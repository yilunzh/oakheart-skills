# Review guide

## Judge rubric
Score each area from 1–5 with specific evidence:
1. Brief fidelity
2. Symbol accuracy
3. Visual quality
4. Typography and copy
5. Preservation of locked elements
6. Production-readiness honesty

## Required verdict
Return one of:
- PASS
- REVISE
- REJECT

## Automatic reject conditions
- wrong selected version used
- unauthorized layout or copy changes
- missing required person/animal/symbol
- obvious spelling or script error
- misleading vendor-readiness claim

## Independence rules
Independent review requires a separate run or agent execution with isolated context. A same-thread self-critique is useful, but must be labeled self-review.
