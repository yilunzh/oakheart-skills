# Production guide

## Core rule
A visually engraved-looking image is not the same thing as production-ready engraving artwork.

## Checklist
- Confirm the locked master source file.
- Preserve composition unless the user explicitly authorizes a change.
- Remove only simulated background effects that interfere with fabrication.
- Evaluate smallest text, finest lines, and densest textures at the intended physical size.
- Distinguish original artwork, cleaned derivative, traced/vectorized derivative, and vendor-validated production art.
- Ask the vendor for actual line/gap constraints and preferred formats.

## Claims to avoid
- “This is engraving-ready” unless the required process, size, and constraints were actually checked.
- “This SVG is vector-ready” when it is merely an automatic trace or an embedded raster.
- “600 DPI” as proof of detail when it is only resampling.
