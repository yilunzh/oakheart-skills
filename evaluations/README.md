# Evaluating shared skills

Packaging checks run automatically. Model evaluations require real executions and remain separate.

For each behavioral candidate, freeze the source commit, input digest, task brief, starting artifacts, tool access and budget. Run the previous and candidate versions on the same platform with fresh workers; compare their finished artifacts using the skill's rubric and objective requirements. Repeat on each affected platform. A Codex win does not establish a Claude win.

Cover the target failure, success preservation, a non-trigger case and transfer to another task family. PTC, AutoNation and Oakheart can supply authorized development benchmarks when their original starting artifacts are available. Their completed outputs are quality references, not clean unseen tests. Keep confidential inputs and protected holdouts outside this repository.

Record runtime/model when exposed, skill digest, artifact references, objective failures, blind findings, ties, corrections needed and missing checks in the existing learning-loop ledger. Follow its stricter access-separation, human calibration and promotion policy. A same-context review or shared-workspace worker cannot prove a protected holdout.

No cross-platform task-quality result is claimed by version 0.2.0. Its new checks cover reproducible packages, installation receipts, conflict detection and failed-update recovery.
